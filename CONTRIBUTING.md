# Contributing

Thanks for helping keep this list useful.

- **One link per pull request**, added to the end of the right section (or alphabetically in "AI ad creative tools").
- Format: `- [Name](https://link) - Short factual description.` Start the description with a capital letter, end it
  with a full stop, and describe what the resource does, not how good it is.
- **Official sources first.** For ad libraries, specs, APIs and MCP servers, link the platform's own page.
- **Open-source tools** must have a public repository with a license and a commit in the last 12 months.
- **Commercial tools** are welcome when they are about making or running ads with AI. No affiliate or tracking links.
- Check the link works without signing in, where the resource allows it.

Pull requests are checked with [awesome-lint](https://github.com/sindresorhus/awesome-lint).
